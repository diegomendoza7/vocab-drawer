# Language-learning audit implementation

This implementation addresses the audit's reliability problems, creates a guided learning route, and adds a free local media/subtitle workflow. The original reference and exercise catalogue remains available in the practice library. Changes are in the workspace; nothing has been deployed or published.

## Reliability and learning evidence

| Audit finding | Implementation |
|---|---|
| F01: wrong-language session writes | Session ID and language are captured; language/rail changes commit before navigation and stop audio/capture. Pending result identities are checked. Import/check responses are discarded after a language switch. |
| F02: saving indicator hides failures | Serial IndexedDB writes resolve at transaction completion. Loading/saving/saved/failed states, retry, exportable in-memory work; failed load cannot silently overwrite stored progress. Exclusive browser writer locks and atomic compare-and-set prevent stale tab writes. Attachment removals update the current profile to avoid restoring another removed reference. |
| F03: interruption loses scheduling | Answer snapshots persist with each progress update. Recovery schedules valid pending results once using committed session IDs. It resumes learning records, not the entire old screen/queue. |
| F04: backup inflation/loss | Schema v3; immutable answer-event IDs; conservative legacy counts; timestamp card conflict resolution; all supported profile fields; timestamp merging for edited phrases, rewrites, and pause changes; separate merge/restore; pre-import snapshot and undo. Binary media remains local. |
| F05: unavailable grammar reports clean | Null score for unassessed writing; checker/coverage/version/date retained. Lesson totals and mistake repair require relevant assessment to claim success. |
| F06: permanent difficult-card lock | Current rehabilitation and lifetime history separated; delayed successes restore harder tasks; production prompts remain available. Word repair offers contextual teaching, personal phrases, delayed checks, and pause/resume. |
| F07: readiness does not refresh | Explicit readyAt for learning/relearning; clock/focus/visibility refresh; waiting message. |
| F08: direction/retention disagreement | Separate recognition and production; production is never inferred from recognition; observed elapsed gaps support retention claims; forecasts and due queues include both directions. Legacy interval claims are labelled estimates. |
| F09: assistance treated as recall | Choices, reconstruction, read-aloud, and dictation are practice evidence rather than lexical production scheduling. Hint/answer access is tracked; first independent mistakes remain failures. Successful early practice does not advance an established card. |
| F10: speech overlap overclaims ability | Read-aloud labelling, negation/order-aware evidence, no lexical production schedule from read-aloud; local record/playback and self-reported personal tasks. No phoneme-level score. |
| F11: audio/offline contract | Bundled continuous audio, explicit downloads/size/readiness, synthetic-source labels, caption import for unsupported voices; unsupported dictation is labelled copying and marked assisted. |
| F12: access/contrast problems | Accessible paragraph word lookup, labelled fields, skip links, focus treatment, darker text accent, mobile navigation/text scaling, reduced-motion support. Automated sampling plus keyboard/browser tests. |
| F13: unsuitable beginner default | Today begins with an A1 introduction mission; 61 additional function words/patterns; 30 short missions teach patterns before personal use. |
| F14: unstructured feature breadth | Guided time/goal route; primary destinations plus grouped practice library; distinct input/output/form/fluency suggestions and optional per-language foreground time. |
| F15: startup/offline freshness | C1 and new heavy views loaded on demand; model worker excluded from base cache; local fonts; content-hashed service-worker version; only owned caches removed; audio/caption editions version downloaded packs. |
| F16: maintainability/tests | Persistence/recovery, progress schema, subtitle parsing, time tracking, task routing, speech evidence, and new activity surfaces extracted. Content integrity scripts, unit regressions, reproducible browser checks. The old exercise controller remains large and merits further incremental extraction. |

## New learning activities

| Idea | Shipped first version |
|---|---|
| Communicative missions and repair strategies | 15 situations per language: introductions, café, directions, shopping, routine, people, clarification, tickets, hotel, plans, meetings, pharmacy, retelling, opinions, and complaints. Learn → listen → understand → own response → reflect. |
| Meaning-focused listening | Two synthetic dialogue voices, independent detail question, optional target/English transcript, learner response. Full conversation-level or multi-question assessment remains editorial work. |
| Sound laboratory | Eight sound contrasts, human model where one exists, synthetic fallback otherwise, local recording/playback, guided self-review. |
| Repeated retelling | Familiar meaning at optional 60/45/30-second rounds; model script can be hidden; recording and can-do self-review. |
| Personal journal | Text, voice, and local JPEG/PNG/WebP photo attachments; grammar coverage, persistent text draft, dated next-day rewrite and comparison. Changed text cannot inherit an older in-flight grammar score. Late microphone grants release their tracks. |
| Phrase notebook | Saved text, meaning, source, media position, independent wording recall, first-word/model scaffolds with a cooldown and hidden notebook answers during recall, separate phrase schedule, edit and pause/resume. Open semantic equivalence is not automatically graded. |
| Weekly transfer | Twelve distinct scenarios, audio/captions, listening detail and new personal response. Can be revisited; “unseen” does not certify that a previously visited task is new. |
| Extensive reading | Thirty existing levelled passages in a lighter reading mode, continuous audio, optional translation, ungraded reading completion. Longer books remain user-supplied media/text. |
| Contrast clinic | Six authored French/German patterns plus lessons from saved personal mistakes, original wording, safely reconstructed saved suggestions, rule explanations, persistent drafts, and a new personal sentence. Missing suggestions are not invented. A complete curated lesson for every external grammar rule remains editorial work. |
| Human listening | Four French fables and two German Grimm stories; 14.9 minutes of original licensed human recordings. Gist/detail prompts where source meaning is known, ungraded reflection otherwise, notes, recording/retelling, offline download, and Media Studio entry. Verified bilingual transcripts are not bundled for these recordings. |
| Skill passport | Dated personal tasks, separate listening/checker evidence, self-report labels, observed word retention; no CEFR certification. |
| Interest packs | Daily route chooses travel, work, family, everyday or interests missions; existing themed words/reading remain accessible. This is a pilot topic route, not a complete level-by-level curriculum. |
| Device continuity | Validated versioned file export, merge/restore, recovery, active-tab protection, and a device-file manager with download/deletion. Automatic server/account sync remains a separate service. |

## Free media workflow

Local audio/video or direct public media URLs; SRT/VTT plus optional English; offsets, replay/loop/pause, speed, transcript search, accessible lookup, rule-based pattern notes, editable subtitle wording, dictation, shadowing, recording, phrase capture, notes, VTT export, and optional local media persistence.

Optional Whisper tiny and OPUS translation run in a lazily loaded WebAssembly worker. Immutable model revisions are pinned; optional app-scoped installation verifies sizes and SHA-256/Git blob hashes before marking a model complete. Speech uses a full-precision encoder and quantized decoder; installation descriptors distinguish this variant from the older all-quantized files. English captions translate recognized text with OPUS rather than use tiny Whisper's unreliable direct English generation. The WASM runtime/module come from the integrity-checked package installation and are served by this app rather than an external CDN. They load on demand and retain the ONNX Runtime MIT licence. Media Studio exposes model preparation, cache clearing, and approximate storage. Installation metadata can recover offline, while binaries use the SDK's browser cache. Cancel/failure leaves subtitle imports usable; cancelled dynamic imports cannot start a late worker. No inference audio/text is sent to a paid API.

Hugging Face/CDN and Wikimedia downloads now succeed in this running instance. All three model sets passed size/hash verification. `npm run test:models` passed real French/German human-speech recognition, English speech captions, and text translation, with all external HTTP requests blocked. French uses an 18-second fable excerpt; German uses 30 seconds of the story after its Librivox introduction. Tests check expected spoken meaning, nonempty timestamped chunks, and English translation. Machine wording is still approximate; these excerpts do not establish general accuracy or suitability on low-end devices. The saved environment contains the required domains and startup instructions; publication remains the user's action.

Full shows work with existing subtitles and a browser-compatible media file. Generating captions is limited to clips of 15 minutes/200 MB to contain memory use. An optional Chrome/Edge MV3 extension now overlays an accessible HTML5 player: imported target/English subtitles, exposed native captions where available, replay/loop, speed/offset, rule notes, and compatible phrase JSON export. It uses only activeTab/scripting, makes no network requests, and extracts no protected streams/private subtitle APIs. It was tested against an actual HTML5 video fixture; particular streaming services and cross-origin iframes are not certified.

## Content, performance, and validation

- 2,977 vocabulary entries, including 61 new lower-level function words/patterns; legacy card identities remain compatible.
- 30 missions + 12 fresh challenge scenarios; captions are generated from the authored script with measured audio segment durations.
- 92 additional synthetic assets, 54.7 minutes, about 16 MB; six human stories, 14.9 minutes, about 7.7 MB; 215 pre-existing human word recordings retain their credits. Synthetic MP3 checksums, bytes, durations, exact dialogue caption text, cue bounds, and question answer indices are audited. Original human byte counts/SHA-1 and local SHA-256 match, and complete Commons source/licence metadata is preserved.
- Initial application JavaScript decreased from approximately 551 KB gzip to 409,251 bytes gzip (400 KiB) across the final HTML’s 11 entry/preload chunks. C1/model chunks are optional; no claim is made about low-end hardware inference speed.
- Regression checks cover grading/direction, real delayed evidence, relearning/rehabilitation, immutable event merges, complete restore, interruption, subtitle formats/offsets/overlap/export, unavailable assessment, negation, and route budget.
- Validation on 2026-10-14: **22 test files, 503 tests; 33 browser checks**, production/extension builds, content audits, lint, and Git diff whitespace checks passed. Real model inference now also passes both languages. Model evidence is recorded in `/workspace/language-learning-audit/model-evidence/`; earlier regression evidence is preserved in `/workspace/language-learning-audit/remaining-evidence/`. The large static vocabulary chunk and two pre-existing harvest-script lint warnings remain.

Browser checks use disposable profiles and owned servers, covering playback/captions/loops, local notes/files, photos, journal drafts and stale/failed assessment, fake-device and late-granted voice capture, human recording attribution, a real video extension overlay and compatible phrase export, personal mistake lessons, secondary-tab/atomic-write protection, offline model metadata, new views, real backup import, keyboard lookup, mobile text controls, interrupted scheduling, language switching, storage faults, timed readiness, sampled axe WCAG checks, and production offline audio.

A separate production Media Studio check generated captions from the original French human OGG recording, translated the existing target track into English, and saved both tracks with expected spoken meaning while external HTTP requests were blocked. Existing target captions are reused for English creation to avoid a second recognition pass. An earlier short resampled WAV excerpt lost a key word in translation; that quality failure is preserved alongside the passing original-recording evidence. Generated literary wording remains noticeably approximate and needs review. Successful tests do not establish universal caption accuracy.

## What still needs longitudinal or external validation

A code change cannot establish that a curriculum teaches a language better. Pilot the authored missions with learners and qualified French/German reviewers; measure unaided delayed recall, comprehension of new content, and fulfilment of communicative tasks rather than catalogue counts. The human library adds narrated stories; independently licensed conversations and broader accents remain valuable additions requiring source and editorial review.

Per-sense lexical IDs, full morphology/government/register coverage, and all plausible equivalent responses need a curated data migration rather than mechanically inventing senses from English glosses. Current compatible word IDs and contextual phrase records remain; no destructive mass remapping was performed. Spelling/article/meaning diagnostics can be extended using clearer task-specific evidence. FSRS comparisons require a trustworthy event history and measured retention target; this release fixes evidence before promising a different scheduler is superior.

Automatic cross-device conflict resolution, service-specific streaming-player support, full conversational scoring, phoneme assessment, and complete CEFR calibration remain separate projects. Local tab overwrites are prevented and a basic video extension is supplied. Model inference is verified on the cloud Chromium device; broader hardware, codec, and caption accuracy checks remain useful. Automated accessibility samples do not replace assistive-technology and teacher/learner usability testing.
