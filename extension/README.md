# Vocab Drawer browser study panel

Unzip the package, open Chrome/Edge’s extension manager, enable Developer mode, and choose **Load unpacked** for the extracted folder. Pin the extension if useful.

Open a video page, click the extension, and import French/German and optional English SRT/VTT files. Choose **Open study panel**. Replay/loop a line, adjust speed/timing, read selected pattern notes, and save phrases. **Use page captions** reads text tracks exposed by an ordinary HTML5 player; some players do not expose them. No audio, subtitles, browsing history, or notes are uploaded by the extension.

Export saved phrases before closing the panel. Import the JSON in the app’s **Backups & device transfer → Merge this backup**. The merge adds phrases while preserving your learning history.

The extension needs only activeTab and scripting access after your click. It has no permanent access to every site. It does not download protected streams, bypass DRM, or retrieve private streaming-service subtitle APIs. Media in cross-origin iframes and service-specific players may require a separate integration. Existing imported tracks work with accessible media elements. Streaming-service compatibility is not certified.
